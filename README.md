# Классическое фэнтези

Небольшая консольная пошаговая игра на **C#**, в которой игрок управляет странствующим рыцарем и сражается с тремя противниками.

## Описание

Игроку предстоит пройти три последовательные волны:

1. **Гоблин-разведчик** — 45 HP, базовый урон 6.
2. **Орочий вождь** — 80 HP, базовый урон 14.
3. **Дракон** — 135 HP, базовый урон 18.

Во время каждого хода игрок выбирает одно из четырёх действий: обычная атака, специальная способность, оборона или восстановление выносливости.

## Характеристики героя

| Параметр | Значение |
|---|---:|
| Здоровье | 150 / 150 |
| Выносливость | 75 / 75 |
| Восстановление выносливости | 3 использования |

После завершения волны рыцарь дополнительно восстанавливает **10 HP** и **10 выносливости**. Значения не могут превышать максимальные.

## Доступные действия

### 1. Базовая атака

Наносит случайный урон от **12 до 17** единиц.

Базовая атака не расходует выносливость.

### 2. Специальная способность

Наносит случайный урон от **25 до 35** единиц и расходует **15 выносливости**.

Если у рыцаря меньше 15 единиц выносливости, способность не выполняется, а ход не передаётся противнику.

### 3. Оборона

Рыцарь принимает защитную стойку.

Получаемый в текущем ходу урон уменьшается **вдвое**. Минимальный получаемый урон — 1 единица.

### 4. Восстановление выносливости

Восстанавливает **20 единиц выносливости**.

Всего это действие можно использовать **3 раза** за всю игру. Выносливость не может превышать 75.

Если восстановления закончились, действие не выполняется, и ход можно выбрать заново.

## Ход боя

Каждая волна проходит по следующему принципу:

1. Отображаются HP рыцаря, выносливость и здоровье противника.
2. Игрок выбирает действие от 1 до 4.
3. Программа проверяет корректность введённого значения.
4. Выполняется выбранное действие.
5. Если враг побеждён, начинается следующая волна.
6. В противном случае противник атакует.
7. Если HP рыцаря становится равным 0, игра заканчивается поражением.

Урон противника генерируется случайно в диапазоне от `базовый урон - 2` до `базовый урон + 2`.

## Условия победы

Для победы необходимо победить всех трёх противников:

**Гоблин-разведчик → Орочий вождь → Дракон**

После прохождения всех волн выводится сообщение о победе и оставшиеся значения здоровья и выносливости рыцаря.

## Условия поражения

Если здоровье рыцаря становится равным **0**, игра немедленно завершается и выводится сообщение:

> РЫЦАРЬ ПОГИБ...

## Запуск проекта

Для запуска потребуется установленный **.NET SDK**.

Если файл находится в обычном консольном проекте C#, выполните:

```bash
dotnet run
```

Если необходимо создать проект с нуля:

```bash
dotnet new console -n FantasyGame
cd FantasyGame
```

Затем замените содержимое `Program.cs` кодом игры и запустите:

```bash
dotnet run
```

## Управление

Во время боя программа предлагает выбрать действие:

```text
1 — Базовая атака
2 — Специальная способность
3 — Оборона
4 — Восстановление выносливости
```

Для выбора нужно ввести соответствующее число и нажать **Enter**.

Некорректный ввод обрабатывается программой: необходимо ввести число от 1 до 4.
